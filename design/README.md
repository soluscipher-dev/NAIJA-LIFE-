# Design folder

- `design-tokens.json` - colors, fonts, spacing, radii, motion (source for the Tailwind theme)
- `style-guide.html` - open in a browser to preview the look (mobile width recommended)

Rules: original assets only, AA contrast, tap targets >= 44px, mobile-first (390px design width).
See `docs/17_UI_UX_DESIGN_SYSTEM.md`.
