# Launch Checklist

## Product
- [ ] Final name, logo, domain, trademark check
- [ ] Onboarding completion >= target in beta
- [ ] Economy dashboards live and reviewed for 4 weeks
- [ ] No open critical/high bugs

## Security and safety
- [ ] Security review complete (doc 15 checklist)
- [ ] Penetration test (self or external) on auth, ledger, admin
- [ ] Rate limits and kill switches verified in production
- [ ] Moderation team/process ready, reports SLA defined
- [ ] Admin 2FA enforced

## Legal
- [ ] Terms of Service, Privacy Policy (NDPA), Community Guidelines
- [ ] Age policy implemented
- [ ] Company registered, tax and bookkeeping set up
- [ ] Asset licenses on file (art, fonts, sounds)
- [ ] Originality log completed
- [ ] No gambling/cash-out mechanics confirmed

## Infrastructure
- [ ] Production env, secrets, backups, restore drill done
- [ ] Monitoring, alerting, on-call plan
- [ ] CDN, TLS, WAF configured
- [ ] Load test passed at 2x expected launch traffic
- [ ] Status page / support channel

## Growth and support
- [ ] Analytics events verified
- [ ] Support email/form, FAQ in Help app
- [ ] Community channel (WhatsApp/Telegram/Discord) with rules
- [ ] Launch announcement and invite system
- [ ] Rollback and incident runbook printed

## Post-launch (first 30 days)
- [ ] Daily review of errors, economy, reports
- [ ] Weekly economy tuning log
- [ ] Hotfix process rehearsed
