# ADR-0004: Generic organizations model

**Status:** Accepted  **Date:** 2026-10

## Context
The vision includes private companies, government, police, courts, parties and media.

## Decision
One organizations model (type, offices, roles, members, ledger account, permissions) serves all of them.

## Consequences
- Government is added later without rewrites.
- Permission checks must be organization-aware from the start.
